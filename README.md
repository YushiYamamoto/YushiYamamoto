## 🚀 **Featured Projects**

### [n8n-nodes-dify](https://github.com/YushiYamamoto/n8n-nodes-dify)

**n8nとDify APIを接続する連携ノード。**
チャット・ワークフロー実行・テキスト生成などの操作を扱います。READMEには導入方法、認証設定、ストリーミングやAI Tool利用の制約を記載しています。

### [agent-memory-lab](https://github.com/YushiYamamoto/agent-memory-lab)

**エージェントの記憶を検索する仕組みの個人検証。**
TiDBのベクトル検索と全文検索の結果を統合する実装です。READMEに実行手順とSQL実行結果の画像を、[tests](https://github.com/YushiYamamoto/agent-memory-lab/tree/main/tests)に検索・統合・SQL生成等の検証コードを置いています。

### [itprodx-sakura-ai-poc](https://github.com/YushiYamamoto/itprodx-sakura-ai-poc)

**問い合わせ分類・FAQ検索・返信下書きを作るPoC。**
架空FAQを使い、実顧客データを含めずに検証する構成です。API利用回数の記録と停止処理、トークン不要のオフライン検証手順を含みます。

これらは公開部品・個人検証・PoCです。顧客への本番導入実績とは区別しています。

## 🛡️ **Design & Quality**

- 要件、入力・出力、完了条件を先に整理する
- AI生成コードも、責務・主要分岐・エラーや中断後の状態をレビューする
- 型チェック・テスト・必要な動作確認を行い、実施した検証と未確認の範囲を分ける
- 自動実行の範囲と、人が確認・承認する工程を決める
- 採用した設計の理由と、制約・運用上の注意を説明できる形にする
